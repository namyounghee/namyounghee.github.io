## 파일 구성

## 글자나 가격을 고치고 싶을 때
1. 이 저장소에서 `index.html`을 누르고 오른쪽 위 연필(편집) 버튼을 누릅니다.
2. Ctrl+F로 고치고 싶은 문장을 찾아 바꿉니다. (예: `80,000원`, `297개`)
3. 아래 초록색 `Commit changes` 버튼을 누르면 1~2분 뒤 홈페이지에 반영됩니다.
